# Contributing

Issues, reproductions, documentation corrections, and proposed public rides are welcome after the repository is published.

Code contributions to this repository are made under `AGPL-3.0-only`. Do not submit proprietary code, customer data, credentials, production traces, or content that you do not have the right to license.

The planned A2AParkBench service is not developed in this repository. A contribution here does not grant permission to access future private services or content, and maintainers will not copy third-party contributions into proprietary components without a separate written grant of rights.

Before accepting substantial external code, the operator will decide whether an additional contributor licence agreement is needed to preserve commercial-licensing flexibility for the public engine.
