# Private ride attribution report

Run `npm run rides:report` in the existing A2APark Render Shell. The command reads the production completion ledger and its new `ride-attribution.jsonl` companion on the same persistent disk. It prints aggregate counts by UTC day, entry route, coarse source and test class; no HTTP endpoint exposes the report. `operational_completed` excludes marked internal rides, verified tests, and completions without a start record. It is a ride count, not a count of people; unclassified rides may still include unmarked internal activity.

The completion ledger remains the authoritative count of completed rides. The companion records future starts only. Its fields are the existing random run ID, start time, server-derived entry route (`web_demo`, `web_browser`, `mcp`, or `a2a`), a broad website referring domain or recognized campaign code, and test class. It has no IP, user agent, fingerprint, full URL, tab/session ID, account or ride content. MCP and A2A have no inferred website referrer. `direct_or_unknown` means only that no supported source was supplied; `unclassified` is not proof of an outside user. Common two-part public suffixes are handled; other uncommon country suffixes may group more coarsely.

The existing `?internal=1` browser switch marks website rides `self_marked_internal` and still excludes browser analytics as before. A configured `RIDE_ATTRIBUTION_TEST_TOKEN` lets controlled clients send the matching `X-A2APark-Test-Token` header to mark a ride `verified_test`; the token is never written to a record. No token is needed for ordinary rides. Missing or wrong tokens leave rides `unclassified`. Do not place this token in public site code or repository files.

The 55 production completion records counted by the owner on October 10 predate this sidecar. They remain `legacy_or_missing_attribution` in the report; no historical record is rewritten or guessed. Open a new dated measurement baseline only after controlled local and production-safe checks pass. Do not send a production test ride solely to initialize this report.
